# Lavista (lavistalawncare.com)

Websites, Google Business Profiles and crew hiring pages for lawn care and landscaping companies in metro Atlanta. An RMDW company.
Static site. Deploy = push to main (Vercel project lavista-lawncare). The "Book a free call" form posts to https://rmdw.ai/api/lavista/lead, which emails info@rmdwllc.com.
samples/ holds two made-up sample client sites (Sweetgum, Red Clay) built on samples/shared.
The old Next.js quoting tool is preserved on branch archive/ai-quoting-tool.
